## 🌟 Overview & Highlights
This project is an all-in-one, production-grade luxury web application for **Payal Manufacturing Hub**, crafted inside `c:/xampp/htdocs/payal/index.html`.

### Key Features Implemented:
1. **Royal Ornate Vector Identity**:
   - Recreated the royal gold crest, 5-point imperial crown, and deep maroon serif letter **'P'** as a crisp, transparent SVG vector graphic that scales flawlessly without any white background boxes.
   - Luxury Indian palette: Deep Royal Maroon (`#4E0312`, `#6D071E`), Champagne Cream / Warm Ivory (`#FAF7F2`, `#F5EFEB`), Antique Gold gradients (`#C59B27`, `#D4AF37`), and crisp White.

2. **Luxury Editorial Experience**:
   - **Hero Section**: 3D perspective tilt card showcasing high-definition Indian ethnic model photography, gold dust particle effects, and dual primary CTAs.
   - **Craftsmanship & Trust Strip**: Fine Stitching, Premium Quality, Safe Packaging, and All India Delivery.
   - **Curated Collections Showcase**: Lehenga Choli, Sarees, Bridal Wear, Party Wear, Festive Wear, and Designer Collections.
   - **Interactive Product Catalogue**:
     - Real-time instant search by name, fabric, color, or occasion.
     - Category filter pills.
     - "Price on Enquiry" & "Contact for Wholesale Price" display badges (customizable by Admin).
     - Individual Product Detail Modal with image gallery & thumbnail switcher, detailed fabric & embroidery specifications, and one-click direct WhatsApp integration.

3. **Wholesale & B2B Lead Engine**:
   - Dedicated Wholesale partner application form.
   - Saves leads directly to the database.
   - Automatic dispatch of notification logs to Admin and confirmation simulation.
   - Direct WhatsApp quote generation with pre-populated business details.

4. **Direct Phone Call & WhatsApp Integration**:
   - Mobile-first calling button linked directly to `tel:+918209206788`.
   - Floating WhatsApp button with pre-filled enquiry template.
   - Mobile sticky bottom action bar: **[CALL]**, **[WHATSAPP]**, **[ENQUIRE]**.

5. **Customer Authentication & Dashboard**:
   - Customer Registration & Login.
   - Saved Wishlist with real-time counters.
   - Enquiry tracking dashboard with live statuses (*New, Contacted, In Discussion, Converted, Closed*).
   - Profile management.

6. **Full-Featured Admin Console**:
   - Discreet access via header lock icon or footer Staff link.
   - **Default Credentials**:
     - **Email / Username**: `admin@payal.com`
     - **Password**: `admin123`
   - **Product Manager**: Add, Edit, Delete, Duplicate, Stock toggle (Available / Out of Stock), Price visibility toggle.
   - **Enquiry Manager**: View customer inquiries, change statuses, click to open WhatsApp chat directly or click to call customer.
   - **Wholesale Leads Manager**: Manage B2B business inquiries.
   - **Customer Directory**: Registered user records.
   - **Simulated Transactional Email Logs**: Review simulated notification emails dispatched for registrations, logins, and inquiries.
   - **Live Website Settings Editor**: Modify business name, phone, email, address, GSTIN, tagline, and hero headlines in real-time.

## 🚀 How to Run Locally

### Option 1: Via XAMPP (Apache)
1. Ensure your XAMPP Apache server is running.
2. Open your web browser and navigate to:
   ```
   http://localhost/payal/
   ```

### Option 2: Direct File Open
1. Double-click `c:\xampp\htdocs\payal\index.html` or open it with Chrome, Edge, or Firefox.
